# Security Policy

If you discover a security vulnerability in this project, please report it privately so we can investigate and fix it before disclosing publicly.

- Preferred: Email security@your-domain.example (replace with repo owner contact)
- Alternatively, open a private GitHub Security Advisory in this repository.

What to include
- Steps to reproduce
- Expected and actual behavior
- Any relevant log output or stack traces
- A minimal reproduction if possible

We will respond within 72 hours and provide status updates until resolved.
